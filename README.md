# Spruce E-Reader

An ebook reader for the Miyoo Flip running spruceOS. Reads epub and txt files.

Features:

- Word selection with Y: look up a word in an offline English dictionary, or highlight it. Highlights are saved per book.
- Typography: headings are larger and bold, italics and bold from the book are kept, quotes are indented and italic, preformatted text uses a monospace font.
- Chapter list on Select, settings on X, themes and fonts as in the original reader.
